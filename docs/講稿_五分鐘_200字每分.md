各位評審、老師好，我是［姓名／隊名］。接下來五分鐘，為大家介紹 RehabBridge——一套把出院後居家復健接回醫療團隊的數位照護平台。

先談市場。台灣高齡人口持續上升，骨科與神經復健患者出院後，八成以上訓練其實發生在家裡，但物理治療師無法每天到府指導，照護責任往往落在家庭。紙本處方常被忘記，做錯了沒人知道，痛了也不知道該不該停；家屬只能反覆催促，醫師要等到回診才看見完成率與疼痛變化。這段「醫師開完處方就失聯」的空白，正是 RehabBridge 要填補的機會。

我們的解法很明確：RehabBridge 是長者、家屬、醫師三端協作的原型 App，可在瀏覽器或 iPad 上執行。核心不是健身娛樂，而是依醫師處方安排每日任務，用手機鏡頭搭配 TensorFlow MoveNet 做即時骨架與關節角度判讀，並以國語或台語語音教練引導。AI 只提供難度建議，臨床決策仍由醫師負責，符合醫療責任界線。

請大家跟著畫面看介面。打開 App，首頁可選長者端、家屬端、醫師端。長者端主頁是「復健闖關」地圖，大字級、一鍵「開始闖關」，今日關卡來自有效處方，下肢與上肢數量都有上限，避免一次做太多。進入訓練後，像膝伸直會啟動相機追蹤，螢幕顯示角度是否達標，並用踢球、火箭等小遊戲回饋，讓長者願意天天練；像下巴內縮則走引導式步驟與計時，結束後回報疼痛、頭暈、腫脹。完成可累積徽章與連續天數，右下角還能開照護團隊聊天。

家屬端是監控儀表板，可看今日完成率、週趨勢與近期紀錄，把「有沒有練」變成看得見的數據，減少家庭焦慮。醫師端則整合患者列表、復健動作庫與新增處方，引導式訓練的異常回報會集中顯示，搭配分數排行與趨勢圖，協助快速決定降階、暫停或聯絡患者。

示範個案是七十二歲的王大明，右膝退化。醫師開立膝伸直與安全引導動作，長者在地圖開始闖關，完成後資料同步醫師端；若回報踝部不穩感偏高，醫師即可調整，形成「開處方、在家練、有回報、能調整」的閉環。

總結價值：對長者，遊戲化與即時糾正提升遵從與信心；對家屬，透明進度取代盲目催促；對醫師與機構，連續數據支援精準照護，緩解復健人力缺口。本專案現為競賽展示原型，已可 Web 與 iOS 實機演示；系統藍圖頁亦呈現架構與機器學習設計，利於後續串接醫院系統與資訊儲存。

RehabBridge 要回答的是：出院之後，這條照護的橋還在不在？邀請各位現場體驗長者闖關、家屬儀表板與醫師處方台。謝謝各位，請多指教。
