RehabBridge / TensorFlow Edge Pose System

基於 TensorFlow 邊緣端點之即時骨架動態感知系統

以瀏覽器或 iOS WebView 作為邊緣推論端點，在本機完成相機擷取、姿態估計、關節角度計算、復健狀態判定、語音回饋與訓練紀錄，形成長者、家屬、醫師三端協作的居家復健閉環。

端側推論影像不需上傳雲端，降低延遲與隱私風險
三端閉環長者訓練、家屬監看、醫師調整處方
安全分流angle / timed / manual 三種追蹤模式

Runtime Pipeline

1
長者按開始RehabSession 啟動 active 狀態
2
相機擷取getUserMedia 前置鏡頭 1280×720
3
模型推論TensorFlow.js estimatePoses 每幀輸出 keypoints
4
角度計算三點關節夾角、可信度過濾、左右鏡像
5
處方比對targetAngle、tolerance、holdSeconds
6
即時回饋骨架、儀表、遊戲、語音提示同步更新
7
安全停機疼痛過高或 guided alerts 進入照護通知
8
紀錄閉環localStorage 訓練紀錄供家屬與醫師端讀取

此圖對應目前專案原始碼：核心推論在 `usePoseDetection`，復健狀態機在 `RehabSession`，資料暫存於 `sessionStore`、`guidedSessionStore`、`prescriptionStore`、`progressStore` 與 `messageStore`。目前為競賽展示與概念驗證原型，非正式醫療器材。
